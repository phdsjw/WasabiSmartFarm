## 🎯 개선 사항 요약

### ✅ 개선된 기능

1. **시계열 꺾은선 그래프 추가**
   - 모든 센서 데이터를 실시간 꺾은선 그래프로 표시
   - 최근 1시간 데이터 자동 업데이트
   - 다중 센서 데이터 동시 표시 (18개 토양, 3개 대기)

2. **직관적인 탭 구성 (5개 탭)**
   - Tab 1: 실시간 모니터링 (평균값 요약)
   - Tab 2: 토양 센서 트렌드 (4개 차트)
   - Tab 3: 토양 센서 히트맵 (예정)
   - Tab 4: 환경 센서 트렌드 (4개 차트)
   - Tab 5: 제어 및 알림

3. **개선된 데이터 시각화**
   - 꺾은선 그래프: 온도, 습도, EC, pH
   - 게이지 차트: TDS (정상 범위 표시)
   - 컬러 구분: 센서별 18개 색상 자동 할당

4. **자동/수동 제어**
   - 자동 모드 ON/OFF 버튼
   - 수동 관수 시작/정지 버튼
   - 긴급 정지 버튼

## 📊 그래프 타입별 적용 센서

### 1️⃣ **꺾은선 그래프 (Line Chart)** ✅

**적용 센서 및 이유**:

#### 토양 센서 (18개)
| 센서 | 단위 | Y축 범위 | 이유 |
|------|------|----------|------|
| **토양 온도** | °C | 0~40 | 시간에 따른 온도 변화 추이 파악 |
| **토양 습도** | % | 85~100 | 관수 전후 습도 변화 모니터링 |
| **토양 EC** | mS/cm | 0~10 | 영양분 농도 변화 추적 |
| **토양 pH** | pH | 5~8 | 산도 변화 장기 모니터링 |

**장점**:
- ✅ 18개 센서의 개별 트렌드 동시 비교 가능
- ✅ 이상 센서 즉시 식별 (다른 센서와 차이 확인)
- ✅ 관수 시점과 효과 시각적 확인

#### 대기 센서 (3개)
| 센서 | 단위 | Y축 범위 | 이유 |
|------|------|----------|------|
| **대기 온도** | °C | 10~35 | 3개 Zone 온도 비교 및 변화 추이 |
| **대기 습도** | % | 30~100 | Zone별 습도 차이 및 환기 효과 확인 |

**장점**:
- ✅ Zone별 환경 차이 한눈에 비교
- ✅ 환기 시스템 효과 확인 가능

#### 수조 센서 (1개)
| 센서 | 단위 | Y축 범위 | 이유 |
|------|------|----------|------|
| **수온** | °C | 10~30 | 수온 변화 추이 파악 |
| **pH** | pH | 자동 | 양액 pH 안정성 모니터링 |
| **EC** | mS/cm | 자동 | 양액 농도 변화 추적 |

**장점**:
- ✅ 양액 조성 시점과 효과 확인
- ✅ pH/EC 듀얼 축 차트로 상관관계 파악

### 1️⃣ **Node-RED에 플로우 가져오기**

#### 방법 A: 웹 UI에서 직접 가져오기 (권장)

```bash
# 1. Node-RED 실행
node-red

# 2. 웹 브라우저에서 접속
http://localhost:1880

# 3. 우측 메뉴 > Import 클릭

# 4. 파일 선택
/home/user/webapp/nodered/flows_improved_ui.json

# 5. Import 버튼 클릭

# 6. Deploy 버튼 클릭 (우측 상단 빨간 버튼)
```

#### 방법 B: 파일 교체 (조심)

```bash
# 1. Node-RED 중지
# Ctrl+C 또는 pm2 stop nodered

# 2. 기존 flows.json 백업
cd ~/.node-red
cp flows.json flows.json.old

# 3. 개선된 플로우로 교체
cp /home/user/webapp/nodered/flows_improved_ui.json ~/.node-red/flows.json

# 4. Node-RED 재시작
node-red
```

### 3️⃣ **Tab별 사용 방법**

#### 📊 **Tab 1: 실시간 모니터링**

**기능**:
- 토양 센서 18개 평균값 (온도, 습도, EC, pH)
- 대기 센서 3개 평균값 (온도, 습도)
- 수조 센서 현재값 (수온, pH, TDS, EC)

**사용법**:
- 자동으로 10초마다 업데이트
- 평균값으로 전체 시스템 상태 빠르게 파악

---

#### 📈 **Tab 2: 토양 센서 트렌드**

**기능**:
- 토양 온도 꺾은선 그래프 (18개 센서)
- 토양 습도 꺾은선 그래프 (18개 센서)
- 토양 EC 꺾은선 그래프 (18개 센서)
- 토양 pH 꺾은선 그래프 (18개 센서)

**차트 특징**:
```
- X축: 시간 (HH:mm:ss)
- Y축: 센서값
- 범례: Tank 01 ~ Tank 18
- 데이터 범위: 최근 1시간
- 색상: 18개 센서별 자동 할당
```

**읽는 방법**:
1. **정상 상태**: 모든 라인이 비슷한 범위에 밀집
2. **이상 센서**: 특정 라인이 다른 센서들과 크게 차이
3. **관수 효과**: 습도 그래프에서 상승 추세 확인

**예시**:
```
토양 습도 그래프:
95% ┤                    ╭───────╮
    ├──────────────────╯         ╰────
90% ┤
    └─────────────────────────────────
    14:00  14:10  14:20  14:30  14:40

👆 14:20에 관수 시작 → 습도 상승 → 14:24에 관수 정지
```

---

#### 🔥 **Tab 3: 토양 센서 히트맵** (예정)

**기능**:
- 18개 토양 센서를 히트맵으로 비교
- 색상으로 높음/보통/낮음 표시

**구현 예정**:
```
Tank01 [■■■■■■■■■□] 96%
Tank02 [■■■■■■■■■■] 98%
Tank03 [■■■■■■■■□□] 95%
...
Tank18 [■■■■■■■■■□] 97%

색상:
🟢 녹색: 정상 범위
🟡 노란색: 주의 필요
🔴 빨간색: 위험
```

---

#### 🌡️ **Tab 4: 환경 센서 트렌드**

**기능**:
- 대기 온도 꺾은선 그래프 (Zone 01/02/03)
- 대기 습도 꺾은선 그래프 (Zone 01/02/03)
- 수조 수온 꺾은선 그래프
- 수조 pH/EC 듀얼 축 꺾은선 그래프

**pH/EC 듀얼 축 차트**:
```
pH (왼쪽 축)    EC (오른쪽 축)
8.0 ┤              ┤ 2.0
    ├──────────    ├
7.0 ┤      ╭───╮   ┤ 1.5
    ├─────╯    ╰─  ├────╮
6.0 ┤              ┤    ╰─
    └──────────────┴──────
    14:00    14:30    15:00

파란선: pH
주황선: EC
```

---

#### 🎛️ **Tab 5: 제어 및 알림**

**기능**:

##### 자동 모드 제어
```
[자동 모드 ON]  [자동 모드 OFF]

현재 상태: ✅ 자동 모드 활성화
```

**자동 모드 로직**:
```javascript
// 관수 시작 조건 (OR)
if (토양 습도 ≤ 95% OR 토양 EC ≥ 5.0 OR 토양 온도 ≥ 22°C) {
    관수 시작
}

// 관수 정지 조건 (AND)
if (토양 습도 > 97% AND 토양 EC < 3.0) {
    관수 정지
}

// 안전 제약
- 최소 관수 간격: 1시간
- 최대 관수 시간: 4분
```

##### 수동 제어
```
[관수 시작]  [관수 정지]  [🚨 긴급 정지]
```

- **관수 시작**: 즉시 관수 펌프 작동
- **관수 정지**: 즉시 관수 펌프 정지
- **긴급 정지**: 모든 액추에이터 즉시 정지 + 자동 모드 해제

## 📊 데이터 흐름

### 센서 → 차트 흐름

```
[Arduino]
   ↓ MQTT Publish
   ↓ Topic: sensor/soil/tank01/data
   ↓ Payload: {tank_id, soil_temp, soil_moisture, ...}
   ↓
[Node-RED MQTT In]
   ↓
[파싱 Function]
   ↓ msg.soil_temp = {topic: "Tank 01", payload: 20.5}
   ↓ msg.soil_moisture = {topic: "Tank 01", payload: 96.3}
   ↓
[차트 노드]
   ↓ ui_chart (Line Chart)
   ↓ 시계열 데이터 저장 (최근 1시간)
   ↓
[Dashboard UI]
   ↓ 실시간 그래프 표시
   ↓ 사용자 확인
```
