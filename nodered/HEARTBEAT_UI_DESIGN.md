## 🎨 노드 카드 디자인

### 1. 온라인 상태 (녹색 램프)

```
┌────────────────────┐
│ 토양센서 01        │  ← 노드 이름
│ 🟢 중요            │  ← 중요도 배지
│                    │
│ ● 온라인           │  ← 녹색 램프 (깜빡임)
│ (35초 전)          │  ← 경과 시간
│                    │
│ 14:32:33           │  ← 마지막 하트비트 시각
└────────────────────┘
  ↑ 왼쪽 테두리 녹색
```

**특징**:
- 왼쪽 테두리: 녹색 (`#4CAF50`)
- 램프: 녹색 원 (깜빡임 애니메이션)
- 배경: 흰색
- hover 시 약간 위로 이동

---

### 2. 타임아웃 상태 (빨간색 램프)

```
┌────────────────────┐
│ 토양센서 02        │  ← 노드 이름
│ 🔴 중요            │  ← 중요도 배지
│                    │
│ ● 타임아웃         │  ← 빨간색 램프 (빠른 깜빡임)

│                    │
│ 14:30:13           │  ← 마지막 하트비트 시각
└────────────────────┘
  ↑ 왼쪽 테두리 빨간색
  ↑ 카드 전체 깜빡임 (pulse 애니메이션)
```

**특징**:
- 왼쪽 테두리: 빨간색 (`#f44336`)
- 램프: 빨간색 원 (빠른 깜빡임)
- 카드 전체: 2초마다 opacity 변화 (주목 유도)


- 타임스탬프 대신 "연결 대기 중..." 표시

## 🎬 애니메이션 효과

### 1. 램프 깜빡임 (온라인 상태)

```css
@keyframes blink {
    0%, 100% { opacity: 1; }
    50% { opacity: 0.3; }
}

.status-dot.green {
    animation: blink 1.5s infinite;
}
```

**효과**: 1.5초마다 녹색 램프가 부드럽게 깜빡임 (마치 심장 박동처럼)

### 2. 카드 깜빡임 (타임아웃 상태)

```css

.node-card.timeout {
```

**효과**: 2초마다 카드 전체가 opacity 변화 (주목 유도)

```css
.node-card:hover {
```

**효과**: 마우스 올리면 카드가 약간 위로 떠오름

## 💡 핵심 답변

### Q: 토양센서 하트비트가 18개이면 18개의 번호와 램프가 있는건가?

**A: 네, 정확합니다!**

```
토양센서 01 → 개별 카드 + 개별 녹색/빨간색/회색 램프
토양센서 02 → 개별 카드 + 개별 녹색/빨간색/회색 램프
토양센서 03 → 개별 카드 + 개별 녹색/빨간색/회색 램프
...
토양센서 18 → 개별 카드 + 개별 녹색/빨간색/회색 램프
```

**총 21개 노드 = 21개 카드 = 21개 램프**

각 노드는:
1. **독립적인 카드**를 가짐
2. **개별 램프**(녹색/빨간색/회색)를 가짐
3. **개별 상태**(온라인/타임아웃/연결안됨)를 표시
4. **마지막 하트비트 시각**을 표시
