# pH 센서 칼리브레이션 도구

**Wasabi SmartFarm - pH Sensor Calibration Tool**

Arduino Uno R4 WiFi 기반 SEN0161 pH 센서 3점 칼리브레이션 도구

---

## 개요

이 도구는 SEN0161 pH 센서의 정확도를 높이기 위한 3점 칼리브레이션 프로그램입니다. pH 4.00, 7.00, 10.00 표준 용액을 사용하여 센서를 보정합니다.

### 주요 기능

1. **3점 칼리브레이션**: pH 4.00, 7.00, 10.00 표준 용액으로 정확한 보정
2. **실시간 pH 측정**: 현재 보정값으로 pH 실시간 모니터링
3. **원시 전압 측정**: 보정 없이 센서의 원시 전압값 확인
4. **EEPROM 저장**: 칼리브레이션 데이터를 EEPROM에 영구 저장
5. **데이터 검증**: 칼리브레이션 완료 후 자동 검증 테스트

## 사용 방법

### 1. 업로드

1. Arduino IDE에서 `ph_calibration_tool.ino` 파일 열기
2. `도구` → `보드` → `Arduino UNO R4 WiFi` 선택
3. `도구` → `포트` → `COMx (Arduino UNO R4 WiFi)` 선택
4. `스케치` → `업로드` (Ctrl + U)

### 2. 시리얼 모니터 열기

1. `도구` → `시리얼 모니터` (Ctrl + Shift + M)
2. 우측 하단 보드레이트: `115200` 선택

```

4. 칼리브레이션 데이터 초기화
5. 원시 전압 측정 (보정 없음)
=====================
명령어를 입력하세요 (1-5):
```

### 4. 3점 칼리브레이션 진행

```

2. 센서를 종이 타월로 물기를 제거하세요.
3. 표준 용액에 센서를 충분히 담그세요.
4. 각 측정 시 약 1-2분 안정화 시간이 필요합니다.
```

```
Step 3/3: pH 10.00 표준 용액 측정
센서를 깨끗이 세척 후 pH 10.00 용액에 담그고 'c'를 입력하세요.
```

1. 센서를 증류수로 세척
2. 종이 타월로 물기 제거

4. 약 1-2분 안정화 대기

#### Step 6: EEPROM에 저장 (선택 사항)

```
칼리브레이션 데이터를 저장하시겠습니까? (y/n):
```

**중요: EEPROM 저장은 선택 사항입니다!**

- `y` 입력: EEPROM에 저장 (칼리브레이션 도구에서 이력 관리용)
- `n` 입력: 저장하지 않음 **(권장)**

**왜 'n'을 권장하나?**
- 물탱크 센서 노드는 EEPROM을 읽지 않고 `config.h`만 사용
- `config.h` 값은 펌웨어에 컴파일되어 플래시 메모리에 영구 저장
- **전원 OFF/ON 시에도 플래시 메모리 값은 유지됨**
- EEPROM 저장은 칼리브레이션 도구에서 이력 관리용으로만 유용

### 5. config.h에 보정값 적용

칼리브레이션 완료 후 출력된 값을 `water_tank_sensor_node/config.h` 파일에 적용:

```cpp
// ============================================
// 🧪 pH 센서 설정 (SEN0161)
// ============================================
#define PH_VOLTAGE_REF 5.0           // 기준 전압 (5V)
#define PH_ADC_RESOLUTION 1024       // ADC 해상도 (10비트)
#define PH_CALIBRATION_OFFSET 0.0234 // ← 여기에 적용
#define PH_CALIBRATION_SLOPE 3.5287  // ← 여기에 적용
```

### 6. 물탱크 센서 노드에 다시 업로드

1. `water_tank_sensor_node.ino` 파일 열기
2. `config.h` 파일의 보정값 확인
3. 업로드

## 기능 설명

### 1. 실시간 pH 측정

현재 저장된 보정값으로 pH를 실시간 측정합니다.

**사용법**:
- 메인 메뉴에서 `1` 입력
- 센서를 측정할 용액에 담그기
- 실시간 pH 값 확인
- `q` 입력하여 종료

**출력 예시**:
```
전압: 2.345 V  →  pH: 6.87
전압: 2.348 V  →  pH: 6.85
전압: 2.351 V  →  pH: 6.84
```

### 2. 3점 칼리브레이션

pH 4.00, 7.00, 10.00 표준 용액으로 센서를 보정합니다.

**특징**:
- 중성점(pH 7.00) 기준 오프셋 계산
- 산성/염기성 구간 기울기 평균 계산
- 자동 검증 테스트
- EEPROM 영구 저장

### 3. 저장된 칼리브레이션 데이터 보기

EEPROM에 저장된 칼리브레이션 데이터를 확인합니다.

**출력 내용**:
- 측정 전압 (pH 4.00, 7.00, 10.00)
- 계산된 보정 계수 (Offset, Slope)
- config.h 적용값
- 검증 테스트 결과

### 4. 칼리브레이션 데이터 초기화

EEPROM에 저장된 칼리브레이션 데이터를 삭제합니다.

**사용 시점**:
- 센서를 교체한 경우
- 칼리브레이션을 다시 진행하고 싶은 경우

### 5. 원시 전압 측정

보정 없이 센서의 원시 전압값을 측정합니다.

**사용 시점**:
- 센서 동작 확인
- 전압값 직접 확인
- 칼리브레이션 전 초기 상태 확인

**출력 예시**:
```
원시 전압: 2.512 V
원시 전압: 2.515 V
원시 전압: 2.510 V
```

## 자주 묻는 질문 (FAQ)

### Q1: EEPROM에 저장하지 않으면 어떻게 되나요?

**A**: 문제없습니다! 물탱크 센서 노드는 `config.h`의 값만 사용합니다.

- `config.h`에 적용한 값은 펌웨어에 컴파일되어 **플래시 메모리**에 저장됩니다.
- 플래시 메모리는 전원 OFF/ON 시에도 **영구 유지**됩니다.
- EEPROM 저장은 칼리브레이션 도구 자체의 이력 관리용입니다.

### Q2: 전원을 끄고 다시 켜면 칼리브레이션 값이 사라지나요?

**A**: 아니요! `config.h`에 적용한 값은 영구 유지됩니다.

**메모리 저장 방식**:
- **config.h** → 펌웨어 → **플래시 메모리** (영구 저장) ✅
- **EEPROM** → 칼리브레이션 도구만 사용 (물탱크 센서 노드는 읽지 않음)

### Q3: 언제 다시 칼리브레이션해야 하나요?

**A**: 다음 경우에 재칼리브레이션이 필요합니다:

- **센서 교체 시**: 즉시
- **정밀 측정 필요 시**: 2주마다
- **일반 사용**: 1개월마다
- **센서 세척 후**: 권장

### Q4: EEPROM 저장이 필요한 경우는 언제인가요?

**A**: 칼리브레이션 도구를 계속 사용할 때만 유용합니다:

- 여러 센서를 순차적으로 칼리브레이션할 때
- 이전 칼리브레이션 데이터와 비교하고 싶을 때
- "3. 저장된 칼리브레이션 데이터 보기" 기능 활용 시

**물탱크 센서 노드 자체는 EEPROM을 사용하지 않습니다.**

### Q5: config.h 값과 EEPROM 값이 다르면 어떻게 되나요?

**A**: 물탱크 센서 노드는 **config.h만 사용**합니다.

- 물탱크 센서 노드: `config.h` 값 사용 (EEPROM 무시)
- 칼리브레이션 도구: EEPROM 값 사용 (별도)
- 두 프로그램은 독립적으로 동작

## 칼리브레이션 원리

### SEN0161 pH 센서 특성

- **이론적 중성점**: pH 7.00에서 2.5V
- **이론적 감도**: pH 1 변화당 약 0.18V (네른스트 방정식)
- **실제 편차**: 센서마다 약간의 오프셋과 기울기 차이 존재

### 3점 칼리브레이션 공식

#### 1. Offset 계산 (중성점 보정)

```
Offset = pH_실제 - pH_측정
pH_측정 = 7.0 - (V_측정 - 2.5) / 0.18
```

#### 2. Slope 계산 (감도 보정)

```
Slope_4_7 = (pH_7 - pH_4) / (V_7 - V_4)
Slope_7_10 = (pH_10 - pH_7) / (V_10 - V_7)
Slope_평균 = (Slope_4_7 + Slope_7_10) / 2
```

#### 3. 최종 pH 계산 공식

```
pH = 7.0 + Offset - ((V - 2.5) / (Slope / 18.0))
```

## 문제 해결

### 전압이 0V로 측정됨

**원인**:
- 센서 연결 불량
- VCC/GND 연결 안됨

**해결 방법**:
1. 센서 연결 확인 (VCC, GND, Signal)
2. 센서 케이블 접촉 확인
3. 센서 전원 LED 확인

### 전압이 계속 변동됨

**원인**:
- 센서 안정화 시간 부족
- 표준 용액 오염

**해결 방법**:
1. 센서를 표준 용액에 담근 후 1-2분 대기
2. 표준 용액 교체 (오래된 용액 사용 금지)
3. 센서를 깨끗이 세척

### 칼리브레이션 후 pH 값이 부정확

**원인**:
- 표준 용액 유효기간 만료
- 센서 오염
- 측정 시 안정화 부족

**해결 방법**:
1. 표준 용액 유효기간 확인 (6개월 이내)
2. 센서를 희석 염산 또는 세척액으로 청소
3. 칼리브레이션 재진행
4. 각 측정 시 충분한 안정화 시간 확보

### EEPROM에 저장되지 않음

**원인**:
- EEPROM 쓰기 실패
- Arduino 메모리 문제

**해결 방법**:
1. Arduino 재부팅
2. 칼리브레이션 재진행
3. 시리얼 모니터에서 저장 메시지 확인

## 유지보수

### 센서 세척 방법

1. **일반 세척** (매번)
   - 증류수로 충분히 세척
   - 종이 타월로 물기 제거

2. **정밀 세척** (월 1회)
   - pH 전극 세척액 사용
   - 30분 담가두기
   - 증류수로 헹굼

3. **오염 제거** (필요 시)
   - 희석 염산(0.1M HCl)에 5분 담그기
   - 증류수로 충분히 헹굼
   - 칼리브레이션 재진행

### 칼리브레이션 주기

- **일반 사용**: 1개월마다
- **정밀 측정**: 2주마다
- **센서 교체 시**: 즉시
- **센서 세척 후**: 권장

### 표준 용액 관리

- **유효기간**: 개봉 후 6개월
- **보관 방법**: 상온, 직사광선 차단
- **사용 주의**: 오염 방지 (깨끗한 비커 사용)
